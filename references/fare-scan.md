# fare-scan 模式：找「最便宜怎么飞」

目标不是排行程，而是在给定出行窗口内，把「直飞 + 各中转枢纽 × 多个候选日期」的往返组合全部列出、读价、**按总价从低到高排名**，直接回答「最便宜的飞法」。

## 何时用

用户诉求是「找最便宜机票 / 最划算出行方式」，而非「要一份行程单」时，走本模式，而不是完整 8 步行程流程。

## 两步用法

### 1) 生成扫描计划（确定性，可离线）

```bash
python scripts/fare_scan.py plan --from PVG --to MLE \
    --window-start 2026-09-25 --window-end 2026-10-07 \
    --min-stay 5 --hubs KUL,BKK,SIN --hub-stay 3 --adults 2 --direct -o plan.json
```

- `--min-stay`：目的地最少停留天数（如马代 5 天以上填 5）
- `--hubs`：候选中转枢纽（马代常用 KUL/BKK/SIN；KUL 亚航最卷）
- `--hub-stay`：中转城市停留天数（顺便玩几天）
- `--direct`：同时纳入直飞做对比
- `--step` / `--max-dates`：候选出发日的步长与数量，控制组合总量

输出 `plan.json`：每个组合含各航段（拆票，分段购买）+ 每段的比价链接，`price.min` 待填。

### 2) 读价后排名

- 在**能连通比价站的机器**（用户本地）上，对每个组合每一段用浏览器打开链接读到最便宜价，填进对应 `legs[].price.min`（单位：元/人）。读价规则见 [fare-reading.md](fare-reading.md)：AI 只读不下单，登录/验证码用户本人完成。
- 然后排名：

```bash
python scripts/fare_scan.py rank --results plan.filled.json
```

输出按单人总价升序的排名表（🥇🥈🥉 + 各段日期与价格 + ×人数总价），缺价组合单列提示。

## 省钱铁律（写进结论）

- **拆票优先**：分段买（PVG-枢纽、枢纽-目的地）通常比联程便宜，中转停留天然规避误接风险。
- **日期弹性**：出发段与转飞段的谷底价常不在同一天，用候选日期矩阵去凑。
- **中转留足缓冲**：KUL 换航站楼（klia↔klia2）留 ≥3 小时。
- **行李分开加购**：廉航基础票不含托运，按需加，别买贵的全包。
- 价格为读价当时值，随库存浮动，下单前以平台实时价为准。

## 环境降级

本 pod 连不上海外比价站时，`plan` 仍可生成（含链接），但 `price.min` 无法自动填——把 `plan.json` 交给用户在本地读价，或用查询链接手动比对。
