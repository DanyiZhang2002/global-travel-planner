# 行旅日记 · 架构说明

## 业务目标

面向个人旅行规划与记录，核心是按日历和时间轴手动维护行程，不做自动攻略生成。

## 关键决策

- React + Vite + qiankun 微应用框架。
- MVP 以浏览器 `localStorage` 保存旅行与行程；刷新页面后仍可恢复。图片在写入前压缩，降低本地存储占用。
- 采用单一视图状态管理页面切换：旅行列表、旅行详情、当日时间轴、新建/编辑旅行、新建/编辑行程。
- `ItineraryItem.details` 存放交通、景点、酒店、餐饮等类型专属字段，保持基础数据结构稳定。
- 未来接入地图、天气、跨设备同步及协作时，保留 `src/api/` 作为统一服务出口。
